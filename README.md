# Portal de Entretenimento Digital

## Sobre o projeto 📽️

Este projeto foi feito como atividade da Agenda 13 do curso de Desenvolvimento de Sistemas da ETEC.

Ele apresenta alguns filmes, jogos e músicas, com imagens e pequenos textos.

## Tecnologias utilizadas 🧑🏻‍💻

- Visual Studio Core
- HTML5
- CSS3

## Estrutura do projeto 🧮

- portal.html: estrutura da página.
- css: estilização da página.
- imagens/: imagens dos sites favoritos.
- Sugestões IA/: Conversa com IA
